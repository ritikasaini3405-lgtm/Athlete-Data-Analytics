# Athlete Data Analytics (1896–2016)

## Project Overview
This project analyses Olympic athlete data from 1896 to 2016 to explore participation trends, athlete demographics, and patterns in sporting performance across different Olympic Games.

Using Python and data analysis libraries, the project transforms historical sports data into meaningful insights through exploratory data analysis, statistical summaries, and visualisations.

## Objectives
- Analyse Olympic participation across different years.
- Explore athlete demographics, including age, height, and weight where available.
- Examine participation and performance patterns across sports and countries.
- Investigate medal distributions and historical trends.
- Apply data visualisation and analytical techniques to communicate findings.

## Methodology
1. **Data Cleaning:** Prepare the dataset and handle missing or inconsistent values.
2. **Exploratory Data Analysis:** Examine distributions, trends, and relationships within the data.
3. **Statistical Analysis:** Summarise athlete participation and sporting performance.
4. **Data Visualisation:** Present patterns using charts and graphs.
5. **Machine Learning:** Apply relevant Scikit-learn techniques where included in the notebook.
